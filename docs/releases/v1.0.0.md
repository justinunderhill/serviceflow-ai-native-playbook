# ServiceFlow Companion — First Edition (v1.0.0)

The first stable release of ServiceFlow, the runnable companion to *The
AI-Native Software Development Playbook* by Justin Underhill. It is a small,
educational FastAPI service that shows one idea in working code:
**authentication is not authorisation**, and the rule is enforced on the
server and proven by negative tests.

## What it does

- Authenticated employees submit requests to an existing manager other than
  themselves.
- Only the assigned manager can approve a pending request; a repeated
  approval is rejected.
- Only the requester and the assigned manager can see a request and its
  audit trail. Anyone else gets the same 404 as for a request that does not
  exist, so they cannot tell which IDs are real.
- Every creation and approval is written to an audit trail in the same
  transaction as the change.

| Situation | Response |
|---|---|
| Not signed in | 401 |
| Request does not exist, or caller is not involved | 404 (identical) |
| Requester tries to approve their own request | 403 |
| Assigned manager approves a pending request | 200 |
| Approving again | 409 |
| Assigning a request to yourself | 422 |

## How it is verified

- 20 automated tests, including negative tests for every refusal above, a
  check that refused actions change nothing, and checks that every database
  connection is closed and that a failed approval rolls back.
- Tests fail on any resource leak (`ResourceWarning`) and run in Python
  development mode.
- CI runs lint and tests on Python 3.11, 3.12 and 3.13 from a locked
  dependency set (`uv.lock`), and the `validate` check is required before
  anything merges to `main`.

## Limitations

This is a teaching reference, **not production software**. It uses HTTP Basic
authentication with disposable local demo accounts and SQLite in a single
process. It has no identity provider, TLS, rate limiting, account lifecycle,
central audit store, migrations or operational monitoring. Response timing
between "missing" and "not yours" is not equalised. Run it on localhost only.
